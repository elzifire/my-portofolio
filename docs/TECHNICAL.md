**Reactive State:**

| Ref | Type | Description |
|---|---|---|

### `useChessTimer()`

Countdown timer with increment support.

**Timer Presets:**

| Mode | Time | Increment |
|---|---|---|
| `none` | ∞ | — |
| `bullet` | 1 min | +0s |
| `blitz` | 3 min | +2s |

| `isExpired` | `boolean` | A player ran out of time |

| Function | Description |

### `useTilt3D()`

3D tilt effect on mouse movement for card elements.

**State:** `rotateX`, `rotateY` — both `ref<number>`, range ±10°.

**Behavior:**
- Listens to `mousemove` on the target element
- Calculates rotation based on cursor position relative to element center
- Resets to `(0, 0)` on `mouseleave`
- Auto-cleans up event listeners on unmount

## Utilities Reference

### `chessBot.ts` — Minimax AI

**Algorithm:** Minimax with alpha-beta pruning.

**Difficulty Mapping:**

| Level | Search Depth | Randomness |
|---|---|---|
| Beginner | 1 | 50% |
| Easy | 2 | 30% |
| Medium | 3 | 15% |
| Hard | 4 | 5% |
| Expert | 5 | 0% |

**Evaluation Components:**
- **Material values:** Pawn=100, Knight=320, Bishop=330, Rook=500, Queen=900, King=20000
- **Piece-square tables:** Position bonuses per piece type
- **Endgame detection:** Switches to endgame king table when material is low
- **Move ordering:** Captures and checks evaluated first for faster pruning

**Key Functions:**

| Function | Description |
|---|---|
| `getBestMove(chess, difficulty)` | Returns the best move with randomness injection |
| `evaluateBoard(chess)` | Score the current board position |
| `minimax(chess, depth, alpha, beta, isMax)` | Core search with pruning |
| `orderMoves(chess, moves)` | Reorder moves for pruning efficiency |

### `ludoBot.ts` — Ludo AI

Weighted heuristic scoring for move selection.

**Scoring Weights:**

| Action | Score |
|---|---|
| Reach goal | +200 |
| Capture opponent | +100 |
| Enter board | +60 |
| Get another turn | +40 |
| Reach safe square | +30 |
| Random variation | ±15 |

**Function:** `pickBestMove(moves[])` — Returns highest-scoring move.

|---|---|
